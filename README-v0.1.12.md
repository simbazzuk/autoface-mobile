# AutoFace Mobile v0.1.12 — Messaging Experience 2.0

- Conversation list now shows the latest message preview and time.
- Per-device new-message indicators use the last time each conversation was opened.
- New-message summary appears at the top of Messages.
- Chat header now includes the connection's photo and name.
- Existing optimistic send, delivery state, date separators, quick replies, limits and polling are retained.
- No fake read receipts, typing state or online presence were added.
- Version 0.1.12; iOS build 8.
